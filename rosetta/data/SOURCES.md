# Where the data files come from

The files the Rosetta Code programs read, each as the task names it, from
the copy Rosetta Code's own runners use.

|---|---|---|

| `words.txt` | https://raw.githubusercontent.com/dwyl/english-words/master/words.txt | the dwyl English word list (the Anadromes task names it); 466,550 words, ASCII with LF line ends, MD5 4f5840aec4cd260b7d1748abb0cdc130 (the alternate copy at thundergnat/rc-run has a BOM, CRLF ends and differs by three words) |
