# Findings

What writing the Rosetta Code tasks in Crow found in the compiler, one program
each (`<task>-<n>.co`, its header saying what it showed, in which mode, and what
was expected). Where each stands, as of 2026-10-29: fixed ones list the tests
that hold them (parity and errors programs whose headers cite the task; a fix
in the runtime may be held by a unit test instead). Run one in both modes with
`crow run -i <file>` and `crow run <file>`.

open: 1, partly fixed: 3, refused before the program runs, by decision: 2, kept as it is, by decision: 1, fixed: 173 — 180 findings.

## Open (1)

- [`weiler_atherton_polygon_clipping-3.co`](weiler_atherton_polygon_clipping-3.co) (Weiler-Atherton polygon clipping): a function nothing calls is not checked for returns of two kinds; the refusal comes once a call types it

## Partly fixed (3)

- [`gaussian_elimination-1.co`](gaussian_elimination-1.co) (Gaussian elimination): a record's field given two kinds by a function's two copies is refused once, naming both (`a list of tensors, and this is a list of lists of fractions that can fail`, errors k15), where its joined type had grown a level each round (79 deep); a follow-on refusal of the program's read of the field still names a kind of neither copy Held by errors k15.
- [`hash_join-1.co`](hash_join-1.co) (Hash join): the refusal now names the two kinds (`a list of Q here where another call makes it a list of P`, errors k13); a first, cascading refusal still blames the handed function's body (`b_of` typed through the first call's `key`) Held by errors k13.
- [`json-1.co`](json-1.co) (JSON): a parsed whole number up to 2^64 − 1 is exact (parity 422); one past 2^64 is rounded by serde_json at the parse, and Vijay decided to leave it so (2026-10-29): keeping every digit would cost all JSON reading Held by parity 392, parity 422.

## Refused before the program runs, by decision (2)

- [`demings_funnel-1.co`](demings_funnel-1.co) (Deming's funnel): a member of a list of functions handed where another call hands a function by name is refused before the program runs (errors k05), by decision
- [`operator_precedence-1.co`](operator_precedence-1.co) (Operator precedence): `not x eq 5` of an int is refused with the fix, `not (x eq 5)`: the spec ranks `not` above `eq`, and the refusal teaches it

## Kept as it is, by decision (1)
