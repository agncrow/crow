# doc

Documentation from Markdown, rendered by the kernel so both execution modes write the same pages.


Import with `use doc`. Documentation from Markdown, rendered by the kernel so the interpreter and compiled programs produce the same pages. The Crow Book is built with it (`docs/book/site.co`).

| Function | Description | Example |
|----------|-------------|---|
| `markdown[text]` | Markdown to HTML: headings get anchor ids, links to `.md` files point at `.html` pages, fenced `crow` blocks are highlighted with Crow's own token rules and tagged `data-mode` (`run`, `error`) | [Documentation: `use doc`](../by-example/doc.md) |
| `chapters[summary]` | An mdBook-style summary (`# Part` headings, `- [Title](path)` items nested by indentation) as a frame with columns `title path depth part` | [Documentation: `use doc`](../by-example/doc.md) |
| `menu[chapters, current]` | Navigation markup for the chapters frame: a brand link, parts as headings, collapsible groups for chapters with sub-chapters (open around the current page), the current page marked, links relative to the current page | [Documentation: `use doc`](../by-example/doc.md) |
| `pager[chapters, current]` | Previous and next chapter links for the current page, in summary order | [Documentation: `use doc`](../by-example/doc.md) |
| `plain[text]` | The words of a chapter with markup removed and whitespace collapsed — what a search index holds | [Documentation: `use doc`](../by-example/doc.md) · [Web: responses and submodules](../by-example/web-more.md) |
| `document[title, body]` | A complete HTML page: the kernel stylesheet (tokens, elements, responsive rules) plus the documentation rules, then the body | [Documentation: `use doc`](../by-example/doc.md) · [Views: the whole element vocabulary](../by-example/views-elements.md) · [View Blocks](../ch12-01-views.md) |

Strings that start and end with a tag pass through a view as markup, so a rendered chapter or a menu can be a child of `stack[...]` or `row[...]`; anything else is text and is escaped. A view's tree handed to `document[...]` is its markup in both modes.

```
use web, ui, doc

view chapter[title, body, nav]
    return row[stack[nav, width = '240px', hidden_below = 'tablet'],
               stack[body, fill = 'true', class = 'doc'], gap = 'xl']

toc = doc.chapters[read['docs/book/src/SUMMARY.md']]
for i in range[len[toc]]
    path = toc.path[i]
    body = doc.markdown[read['docs/book/src/`path`']]
    page = doc.document[toc.title[i], chapter[toc.title[i], body, doc.menu[toc, path]]]
    html_path = replace[path, '.md', '.html']
    write['docs/book/crow-site/`html_path`', page]
```
