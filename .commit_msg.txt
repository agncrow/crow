Implement io module: csv and lines functions

Add io module with two functions:
- csv[path]: parse CSV file into array of maps (column headers as keys)
- lines[path]: read file as array of line strings

Both return error-values on failure. Basic file I/O (read/write) already
exists as builtins - io module adds only structured parsing (rule 17).

Also fix array indexing in transpiler to add .clone() for non-Copy element
types (Map, Array, Str), and add Result-type unwrapping in type inference
for variable indexing.

Files: crow_runtime/src/io.rs, src/modules/io.rs, examples/io_test.crow
Updated: interpreter.rs, transpiler.rs, type_infer.rs, validator.rs,
         docs/language-spec.md
