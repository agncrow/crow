Implement load[] for fast numeric CSV loading

Add load[path] to math module — reads CSV directly into CrowTensor,
skipping intermediate string/map allocations. Benchmarks on 1GB CSV:
- Crow load[] (interpreter): 2.732s
- Crow load[] (transpiled):  2.818s  
- Polars:                    2.928s
- NumPy loadtxt:             4.427s
- Pandas read_csv:           4.492s

Also fix Result(NumArray) property access in transpiler and type
inference — .shape/.dtype/.device/.grad now work on Result-wrapped
tensors.

Files changed:
- crow_runtime/src/io.rs: add load_csv_numeric() + 10 unit tests
- src/modules/math.rs: add load to interpreter, transpiler, type_of
- src/transpiler.rs: handle Result(NumArray) in property emission
- src/type_infer.rs: handle Result(NumArray) in property type inference
- docs/language-spec.md: add Data Loading section
- examples/load_test.crow: example exercising load[]
- benchmarks/: gen_csv.py, bench_csv.py, bench_csv.crow
